# Noverdi Ramadhan

Penetration tester. I do web and API pentests and bug bounty, and I build the tools I keep wishing I had while doing it.

## Tools

- **[burp-snapshot](https://github.com/noverdy/burp-snapshot)**: Burp Suite extension that turns requests, responses and Intruder results into annotated, redacted PNGs for reports.
- **[burp-request-file-inserter](https://github.com/noverdy/burp-request-file-inserter)**: Burp Suite extension that inserts file contents (raw or base64) into requests at the cursor in Repeater.
- **[skills](https://github.com/noverdy/skills)**: agent skills I use for bug bounty and pentesting work.
- **[portswigger-filters](https://github.com/noverdy/portswigger-filters)**: Chrome extension that adds filters to the PortSwigger Web Security Academy lab list.

## Labs and challenges

- **[cosmos-labs](https://github.com/noverdy/cosmos-labs)**: four Dockerised labs (JWT, SQL injection, LFI, XSS) built for the COSMOS security workshop.
- **[yet-another-sqli-lab](https://github.com/noverdy/yet-another-sqli-lab)**: error-based blind SQL injection under a time limit, where only efficient automation wins.
- **[ctf-challenges](https://github.com/noverdy/ctf-challenges)**: challenges I wrote for COSMOS 2023, Codex 2023 and IDSECCONF 2024.
